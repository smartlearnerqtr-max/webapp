# Ichan Assets

Dat asset giao dien Ichan trong cac thu muc sau:

- `subjects/`: avatar/icon cho mon hoc
- `communication/`: the giao tiep
- `games/`: anh dai dien tro choi
- `careers/`: anh dai dien nghe nghiep
- `mascots/`: avatar nhan vat, mat cuoi, sticker
- `backgrounds/`: anh nen dashboard, section, card lon

Quy uoc uu tien:

- Dung ten file khong dau, chu thuong, ngan cach bang `-`
- Uu tien `png` hoac `webp`
- Neu co anh vuong cho card/icon, uu tien ti le 1:1
